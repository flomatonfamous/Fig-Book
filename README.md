# The Backyard Fig
## A Complete Grower's Guide to Varieties, Propagation, Fertilizing, and Year-Round Care

**Author:** Randall White / Flomaton Famous LLC

A complete, publishable fig book combining practical growing knowledge, personal nursery
experience, historical context, and the story of building a fig collection and backyard
nursery in Alabama.

---

## Project Structure

```
fig-book/
├── README.md              — This file. Project overview and navigation.
├── PROJECT.md             — Canonical decisions, locked elements, author notes.
├── STYLE_GUIDE.md         — Tone, voice, and writing rules for all chapters.
├── CHAPTER_LOG.md         — Approval status of every chapter and planning element.
│
├── manuscript/            — Chapter drafts (one file per chapter)
│   ├── 01-chapter-1.md
│   ├── 02-chapter-2.md
│   └── ...
│
├── research/              — Source notes, biblical references, historical facts
│   ├── biblical-references.md
│   ├── fig-history.md
│   └── fig-varieties.md
│
└── notes/                 — Personal story prompts, session notes, ideas
    └── personal-stories.md
```

---

## How to Use This Repo in Cursor

Open the `fig-book` folder in Cursor on any machine. All chapter drafts,
research notes, and project decisions are here. The `PROJECT.md` and
`CHAPTER_LOG.md` files are the two most important reference points at the
start of any working session.
